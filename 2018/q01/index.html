トルエンと水の共沸・有機溶媒の上下層 平成30年度 問1 有機化学及び燃料

有機溶媒に関する次のA～Eの記述の正誤の組合せとして、最も適切なものはどれか。

(A)
20%の水を含むトルエンを常圧で単蒸留すると、まず水が留出し、ついで沸点110.6℃のトルエンが留出する。
(B)
ベンゼンはトルエンより分子量は小さいが、トルエンの融点が～95℃であるのに対して、ペンゼンの融点は5.5℃と高い。
(C)
クロロホルム10 mLと水10 mLとをよく振り混ぜた後に静置すると、クロロホルムは下層として分離する。
(D)
ジェチルエーテル10 mlと水10 mLをよく振り混ぜた後に静置すると、ジェチルエーテルは上層として分離する。
(E)
アセトン10 mLと水10 mLとをよく振り混ぜた後に静置すると、アセトンは下層として分離する。
① 正 / 正 / 誤 / 正 / 誤
② 正 / 正 / 誤 / 誤 / 正
③ 正 / 誤 / 正 / 正 / 誤
④ 誤 / 正 / 正 / 正 / 誤
⑤ 誤 / 誤 / 誤 / 正 / 正
正答
④ 誤 / 正 / 正 / 正 / 誤

正答は④（誤・正・正・正・誤）です。蒸留では共沸の有無、分液では水との混和性と密度を分けて考えます。

蒸留：トルエンと水は一緒に留出する

（A）は誤りです。トルエンと水は共沸し、常圧では約84～85℃で両成分を含む蒸気が生じます。純粋な水だけが先に留出し、その後にトルエンが留出するわけではありません。水とトルエンが液体として二層に分かれることと、蒸留で両成分が一緒に留出することは両立します。

日本食品分析センターの「水分について」表2（3ページ）にも、トルエンと水の共沸点84.1℃が示されています。

融点：分子量だけでは大小を決められない

（B）は正しい記述です。ベンゼンの融点は約5.5℃、トルエンは約−95℃です。融点には結晶中の分子の並び方や分子間相互作用も関係するため、「分子量が大きいほど融点も高い」とは判断できません。

分液：混和性を確かめてから密度を比べる

最初に水と一層になるか、二層に分かれるかを判定します。二層に分かれる場合に、密度の小さい層が上、大きい層が下になります。室温付近の水の密度は約1.00 g/cm3です。

問題のように有機溶媒10 mLと水10 mLを混ぜた場合
有機溶媒水との混和性密度の目安静置後
クロロホルム完全には混ざらない約1.49 g/cm3有機層が下
ジエチルエーテル完全には混ざらない約0.72 g/cm3有機層が上
アセトン任意の割合で混ざる上下の判定は不要一層になる

（C）は正。クロロホルムは水より密度が大きいため下層になります。（D）も正。ジエチルエーテルは水より密度が小さいため上層になります。（E）は誤。アセトンは水と完全に混和するため、上層・下層には分かれません。

表の密度は室温付近の概数です。「完全には混ざらない」は相互の溶解度がゼロという意味ではありません。東京化成の物性値では水への溶解度はクロロホルムが8 g/L、ジエチルエーテルが69 g/L（ともに20℃）で、アセトンは水と完全に混和するとされています。
